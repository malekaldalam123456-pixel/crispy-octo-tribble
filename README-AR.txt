EARN IT — طريقة التشغيل والتثبيت

1) فك ضغط المجلد كاملًا، ولا تنقل index.html وحده؛ ملفات PWA ضرورية للعمل دون اتصال.
2) افتح المجلد في VS Code.
3) شغّل index.html باستخدام إضافة Live Server (مثلاً Open with Live Server).
   أو شغّل من داخل المجلد الأمر:
   python -m http.server 8000
   ثم افتح: http://localhost:8000
4) أنشئ ملفك الشخصي بإدخال الاسم واختيار الصورة.
5) لتثبيت التطبيق: من زر «تثبيت التطبيق» في صفحة الملف الشخصي، أو من قائمة المتصفح.
6) بعد أول تحميل ناجح، افتح التطبيق مرة أخرى دون إنترنت؛ سيعمل غلاف التطبيق والوظائف التي تعتمد على البيانات المحلية.

ملاحظات مهمة:
- تسجيل الدخول تجريبي ومحلي، وليس نظام حسابات حقيقيًا. لا توجد كلمة مرور أو مزامنة بين الأجهزة.
- البيانات والصورة محفوظة في LocalStorage على نفس المتصفح. لا تمسح بيانات الموقع قبل تصدير نسخة احتياطية.
- إشعارات المتصفح تحتاج إذن المستخدم، وقد تختلف طريقة عملها حسب المتصفح والنظام. التذكيرات الدورية داخل الصفحة تعمل عندما يكون التطبيق مفتوحًا.
- لا يمكن تسجيل Service Worker أو تثبيت PWA عند فتح الملف مباشرة بصيغة file://؛ استخدم localhost أو استضافة HTTPS.
- العمل دون اتصال يبدأ بعد زيارة التطبيق مرة واحدة على الأقل مع اتصال إنترنت.
